## Installation & Setup

1. Clone the repository - git clone <repo-url>
2. cd my-app
3. To install the dependencies - npm install
4. To run the server - npm run dev

# Healthcare Dashboard

A fully-featured **Nextjs + Typescript** dashboard and file upload, built with **Styled Components**. The project uses a **monorepo-style architecture** for clean folder organization and reusable component.

# Role-Based Data Restrictions 

• Admin: Full table access, upload option visible. 

• Reviewer: Full table, searching, sorting, filter, but no upload option.

• Viewer: Only first 10 records, no filters.
